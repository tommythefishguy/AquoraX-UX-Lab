AquoraX UX Lab build

This build is for the separate AquoraX-UX-Lab GitHub repo only.

Disabled on purpose:
- Firebase SDK loading
- cloud login gate
- cloud backup / restore actions
- push notifications / FCM
- service worker registration / PWA caching
- Firebase functions deployment files

Why:
This lets you test Beginner/Experienced mode layouts, visual design, navigation,
onboarding, explanations and Ask AquoraX UI quickly without risking the live app.

Do not upload this UX Lab build over the production AquoraX app.
